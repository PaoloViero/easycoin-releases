# EasyCoin Releases

Repository pubblico usato **solo** per l'aggiornamento automatico dell'app EasyCoin.
Non contiene codice sorgente: solo `latest.json` (numero di versione corrente) e,
come Release di GitHub, gli installer firmati.

Il codice sorgente resta privato in [EasyCoin](https://github.com/PaoloViero/EasyCoin).
